Track Viewer

Load a path and/or raw GPS points, then measure distance along the trace.
Import raw GPS fixes to view superimposed on the map and the path above, for comparison. Accepts GeoJSON (Point/MultiPoint), NDJSON (one point object or GeoJSON Point per line), GPX (trkpt/wpt/rtept), or CSV with lat/lon columns.
Automatically joins separate line features whose endpoints are within tolerance of each other (e.g. a track split into multiple segments) into continuous paths, so measurements and path traces can cross between them. Runs automatically on load.
Click a point ON the drawn track to set the start marker (green). Click again elsewhere on the track to set the end marker (red). Distance is computed by following the actual path geometry, not a straight line.
